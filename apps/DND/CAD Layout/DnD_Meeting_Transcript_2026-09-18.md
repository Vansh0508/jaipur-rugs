## Key Points Captured (summary of the discussion)

### Current process
- DnD prepares CAD layouts manually in PPT from a BMP (Tikni) design file.
- The layout format is fixed. Only the file-specific details change: colour references (GRC / ARS codes in sequence), file dimensions, finishing, pile/light details, PD number, wool cut file, size, shape, quality, fibre, and design intent / reference images.
- Colour sequence rule: the colour covering the most area (usually the border) comes first, then the second most, and so on. Some files use up to 11 colours.

### Layout variants
- **B2C** layout.
- **JLI (Jaipur Living)** layout: same details, slightly different layout (construction design, dates, colour boxes, approval/signature boxes).
- **B2B** layout: to be checked, but mostly follows JLI.
- The tool should let the user pick B2C / B2B / Jaipur Living and output that format.
- Multiple-file layouts also exist and must be supported.
- Confirm with R&D whether they follow the same format as DnD.

### Agreed requirements for the tool / portal
- Single-page web form where the user fills only the variable details. Fixed text stays as-is in the template.
- User attaches the Tikni / BMP file. The tool reads colours and their sequence from it automatically.
- Output is the converted layout (PPT / PDF). The raw BMP is never shared in the output.
- Reference / design-intent images: attach via the portal (usually one image, sometimes more). Keep the option open for multiple attachments. No fixed shared folder location, since project folders (e.g. the Bangalore project) would get messy.
- Standard / fixed fields become dropdowns (two or three options each). Free-text fields remain editable.
- Team to be told to mention colour codes in the Tikni file so the tool can pick them up.

### Action items
- **DnD** to share reference layouts (B2C, JLI, and B2B if different), including a multiple-file example, plus BMP files converted to JPG images, in one folder.
- **DnD** to mark which image is the design and which is the reference image in that folder.
- **Automation (Ayaan)** to confirm the B2B layout and the R&D format, and to build the layout conversion tool per the above.
