## Key Points Captured

### What DnD saw and accepted
- The generated JLI deck matched their layout: approval box, reference images, colour boxes in the right places. Multi-option decks and 3–4 reference images per option worked in the demo.
- Colour list behaviour accepted: reorder up/down, remove a colour; DnD also want to be able to **add** a colour manually.

### Decisions
- **The Tikni BMP is never stored** — it stays with the designer. Only the generated PPT + PDF (and the rendered JPEG/PNG) persist. (15:39)
- **Colour codes in the Tikni file:** DnD number the swatches under the legend strip (1, 2, 3…); the colour code is the **last two digits** (e.g. "14"); the yarn used per colour is also written ("silk"). The tool is to read these from the legend automatically. (15:29)
- **B2B is not the same as JLI** — approval box and colour boxes differ, some layouts need a "form reference" extra; **Big Box** has its own layout too (always with 9×12). Expect 4–5 layout variants. DnD will supply each as a folder: PPT + reference image + BMP. "Sab kuch same hi hai, bas thoda upar-niche" — same fields, different placement. (15:36–15:39)
- **Swatch** is a separate attachment from reference images: the designer cuts a piece of the design at the customer's required physical size (30 cm / 45 cm — varies), manually, and uploads it. Placement: bottom-left slot where the design-intent photo sits today, same dimensions; reference images labelled "Reference" go to the right. DnD will send the layout that carries the "Design intent" label. (15:33–15:34)

### Defect reported
- Width/length dimension lines are at fixed positions; with an aspect-fitted design image there's a visible gap between image and lines. Lines must hug the image. (15:37)

### Future scope (noted, not in this build)
- Order sheet generated from the same data ("size aur design name perfect dena hai").
- PD number lookup from the new system replacing Salesforce to auto-fill spec details.
- All D&D and R&D tools in one portal; show R&D (Chavi) so both teams can input.

### Action items
- **DnD:** send folders (PPT + reference image + BMP) for JLI, B2B, Big Box, B2C and any department-specific layouts; send 2–3 example swatch files; send the "Design intent"-labelled layout.
- **Automation (Ayaan):** fix dimension-line gap; drop BMP storage from the design; add swatch upload slot and manual "add colour"; run the sample with DnD, then iterate per layout received; loop in R&D.
